# Al-Emtyaz SVG Icon Pack

Scalable SVG icons created for the Al-Emtyaz recruitment website.

Colors:
- Blue: #2F6798
- Gold: #D8BC4B

All files:
- 256x256 viewBox
- Transparent background
- Vector paths
- Scalable without quality loss
- Suitable for web, Laravel Blade, CSS, Figma, Illustrator, and print

You can recolor them by replacing the HEX values inside each SVG.
